# Desktop guide

Morz desktop stores documents as ordinary `.md` files in a folder of your choice.

## Install

Download the installer from [Releases](https://github.com/cumany/Morz/releases) and run it.
The portable `.exe` also works, but portable builds do not support in-app updates.

## Updates

- Installed builds check for updates from **Help → Check for Updates** or the version entry in
  the status bar.
- The updater checks a China-friendly mirror first, then GitHub. Installer signatures are
  verified; a mirror cannot inject code.
- If the in-app download fails, the dialog offers the release page as a fallback.

## Data

- Notes stay in the folder you choose; Morz never uploads them.
- Backups/trash/history are local. Use **Settings → General → Interface** for language and
  **Settings → Appearance** for themes.
