功能指南 · 对着菜单看

两个版本：Morz（免费）保留编辑与阅读核心，长期可用；Morz 内测版
先拿到正在打磨的功能，稳定后下放到免费版。内测版不承诺时间表，也不保证每个实验功能都会保留。

版本：v0.3.1 · 2026-11-21
怎么用：想知道某个菜单项是干什么的、为什么存在、什么时候该用，按菜单查。
快捷键以 Windows / Linux 为准；macOS 把 Ctrl 换成 ⌘。

β 标记：带 β 的功能仍在测试期，行为可能随版本变化；其余功能按常规稳定性维护。内测版可直接使用下列全部功能，无需账号，本地功能离线可用。

一、文件（File）

文件菜单按 新建 / 打开 / 导入 分组：打开类动作（含最近文档）收进「打开」，导入副本收进「导入」；导出与偏好设置仍在菜单里。保存是自动的，重命名、删除、历史版本、文档属性都在文件树右键或命令面板里，菜单不再重复；关闭文档保留快捷键与命令面板入口，不占菜单。

功能 快捷键 解决什么
新建 Ctrl+N 手边有想法但还没想好放哪：先写，位置以后再说
打开… Ctrl+Shift+O 偶尔处理一个散落在别处的 .md，不想为它建工作区
导入副本… — 把外部 .md / .html / .txt 复制一份到当前工作区并打开（HTML 转成 Markdown）；原文件不动
导入 Word (.docx)… — 把 Word 文档转成 Markdown 收进当前工作区；库里的 .docx 也可以直接在文件树里点开预览，再点「转换为 Markdown」
打开文件夹… — 主力入口：把整个文件夹变成工作区，左边有树、能搜索、能看反链
快速打开… Ctrl+O 记得标题但不想在树里翻：打几个字直接跳
最近打开的文件 — 文件 › 打开 › 最近打开；也可把「最近文档」挂到右栏（右栏空白处右键勾选），随时点开
下一个 / 上一个文件 Ctrl+Alt+PageDown / Ctrl+Alt+PageUp（备用 Ctrl+Alt+↓ / ↑） 文件列表里顺序看下一篇；同目录优先、到末尾回绕。方向键常被显卡/系统热键占用，所以默认用 PageUp/PageDown
后退 / 前进 Ctrl+Alt+←/→ 顺着链接跳了三层，想原路退回（含页内标题跳转）
保存 Ctrl+S 自动保存是默认行为；菜单不再放「保存」，快捷键随时可用
另存为… Ctrl+Shift+S 把这篇文章另起一份，原稿保留（网页版用导出）
从磁盘重新加载 — 在别的编辑器里改过这篇，用磁盘版本覆盖当前视图
关闭文档 Ctrl+Alt+W 收工；有未保存改动会先问（菜单不再放，快捷键/命令面板可用）
重新打开关闭的标签页 Ctrl+Shift+T 误关了一篇，直接找回
重命名… — F2 / 文件树右键直接在行内改名（不弹窗）；链接照常更新，Esc 取消
移动到… — 文件夹骨架选择器（可展开子目录；文件/文件夹右键，当前文档也走命令面板）
拖动文件 / 文件夹 — 拖到文件夹行 = 移入；拖到工作区标题或文件树空白 = 移到根目录；经过文件夹不再自动展开，深层目标用「移动到…」
删除… — 删到回收站，后悔还能捞回来（文件树右键）
在文件列表中定位 — 正文里看到一篇，想回到左侧树里看它旁边还有谁
文档属性… — 看字数、路径、编码、创建/修改时间这些"关于这篇"的信息
偏好设置… — 全局设置入口（也常驻状态栏左下角）

重命名 / 移动 / 删除 / 文件历史 / 文档属性都在文件树右键和命令面板里，文件菜单不再重复；网页版没有「工作区」子菜单，工作区操作在侧栏顶部的文件夹菜单。
新建文件 / 文件夹在文件树右键（空白处=根目录，文件夹行=该文件夹）和顶部「+」；创建后直接在树行里命名（不弹对话框）。侧栏「⋯」只放刷新、排序、折叠和文件计数，不再放新建，避免误建到选中的文件夹里。

1.1 导出（子菜单）

功能 解决什么
PDF 交付/打印：真分页、页码、TOC 页码、侧边书签（Windows 桌面）；导出前可就地改纸张/页边距/是否带主题
HTML 发网页或存档：跟随当前主题，图片内嵌
HTML（无样式） 只要结构，样式由对方定（贴到已有站点里）
长图 整篇按当前主题导成 PNG；导出前可选阅读版/手机宽度和底部标识，太长自动分页打包 zip
Markdown 文件 把当前文档导出成 .md 副本（不动原文件）
Word (.docx) 对方要能改：导航大纲、画廊、Callout、脚注
打印… 走系统打印（macOS/Linux 的 PDF 也在这里）；打印前可就地改纸张/页边距/是否带主题
发布为静态站… β 把整个工作区导出成可直接上传的静态站点

「分享为图片」（选中文字后右键）会把选区排成一张带主题的卡片并复制 PNG；「复制为 HTML 代码」和「复制为 Markdown」在命令面板（Ctrl+P）和正文右键里，不占导出菜单。

1.2 工作区（桌面版子菜单；网页版在侧栏文件夹菜单）

功能 解决什么
管理工作区… 看每个工作区存在哪、切换、在文件管理器中显示、移出列表
回收站… 误删之后捞回来

导出全部文档（备份）… 移到了侧栏顶部的工作区菜单（也在命令面板里）：换电脑/重装前把整个工作区打包带走。文件历史… 在文件树右键和命令面板里：手滑改坏了，按时间点找回这篇的旧版本。

二、编辑（Edit）

编辑菜单只保留撤销/重做、剪贴板、查找替换和全选这些高频项；下面其余命令在正文右键、命令面板和快捷键里，菜单不再重复。

功能 快捷键 解决什么
撤销 / 重做 Ctrl+Z / Ctrl+Shift+Z 写错了往回退；表格里是整格退，不是逐字
剪切 / 复制 / 粘贴 Ctrl+X / C / V 常规剪贴板
复制为 Markdown Ctrl+Shift+C 把选中内容连同格式一起拷走，粘到别处仍是 Markdown（右键/命令面板）
复制为 HTML 代码 — 粘到支持富文本的地方（邮件、公众号）样式不丢（右键/命令面板）
粘贴为纯文本 Ctrl+Shift+V 从网页拷来的内容带着一堆样式，只要字
全选 Ctrl+A 分段式：第一次选当前行（代码块内先选块内容）；在列表项/引用块里再按一次选整个块，最后才是全文；表格里是「本格 → 全表 → 全文」
选择样式范围 Ctrl+Alt+E 光标在加粗中间，想一次选中整个加粗范围
选择行/句 Ctrl+L 整行选中，不用拖鼠标
选择单词 Ctrl+D 快速选中一个词（多光标关闭时的替代）
删除单词 Ctrl+Shift+D 删掉光标所在词
上移一行 / 下移一行 Alt+↑ / Alt+↓ 调段落顺序，不用剪切粘贴
查找… Ctrl+F 当前文档内定位
替换… Ctrl+H 批量改词
查找下一个 / 查找上一个 Ctrl+G / Ctrl+Shift+G 反复找同一个词；搜索面板的按钮悬停也会显示这两个键
跳回光标 / 选区 Ctrl+J 滚远了想回到正在写的地方
在文件中搜索… Ctrl+Shift+F 忘了在哪篇，搜整个工作区
插入表情… — 找 emoji，不用记短代码（工具栏）

三、段落（Paragraph）

段落不再占顶层菜单：这些动作在顶部工具栏和正文右键的「段落 / 列表」里。和格式的分界不变：格式改行内，段落改整块。

功能 快捷键 解决什么
标题 1–6 Ctrl+1…Ctrl+6 建立层级；导出 PDF/Word 的大纲、TOC 都靠它
正文 Ctrl+0 把标题降回普通段落
提升标题级别 / 降低标题级别 Ctrl+= / Ctrl+- 整篇结构要挪一层，不用逐条改
表格… Ctrl+T 插入表格，填行列数即可
表格预览 右键表格 → 预览表格 / 悬停右上角按钮 宽表、长表在弹窗里一屏看全，表头吸顶；「复制表格」一次写入图片/HTML/TSV（粘聊天框是图片，粘回表格是文本）；打印/导出会按页面宽度重新排版
宽表处理 右键表格 → 宽表处理（全局） 默认适应正文；仍放不下时横向滚动。需要按内容排时可切 按内容横向滚动
删除当前表格行 Ctrl+Shift+Backspace 不用右键也能删行（Typora 同款）
代码块 Ctrl+Shift+K 贴代码，带语言高亮
公式块 Ctrl+Shift+M 独立成行的 TeX 公式
引用 Ctrl+Shift+Q 引用他人观点
有序列表 / 无序列表 Ctrl+Shift+[ / Ctrl+Shift+] 列步骤、列要点
任务列表 Ctrl+Alt+X 待办清单，可勾选
切换任务状态 / 标记为完成 / 标记为未完成 Ctrl+Shift+X 等 批量改状态，或统一标成完成
缩进 / 减少缩进 Ctrl+[ / Ctrl+] 列表层级、代码缩进（和 Typora 一致）
上移 / 下移列表项 Ctrl+Shift+↑ / Ctrl+Shift+↓ 连子级一起移动，只在同级兄弟间移动
折叠 / 展开列表项 Ctrl+Alt+[ / Ctrl+Alt+] 长列表收起子项
在上方插入段落 / 在下方插入段落 — 引用块、表格前后插不进字时的出口
链接引用 — 同一地址多处引用，改一处全改（[文字][1] + 定义）
脚注 Ctrl+Alt+R 补充说明不打断正文
分隔线 Ctrl+Alt+- 章节之间断开
目录 — 插入 [TOC]，导出时自动填页码
YAML 元信息 — 给文档加标题/标签/日期等属性（属性卡形式展示）

四、格式（Format）

格式不再占顶层菜单：顶部工具栏覆盖最常用的行内格式，完整列表在正文右键的「格式」里，命令面板也能搜到。

功能 快捷键 解决什么
加粗 / 斜体 / 下划线 Ctrl+B / Ctrl+I / Ctrl+U 强调
行内代码 `Ctrl+Shift+`` 术语、命令、变量名
删除线 / 高亮 — / Ctrl+Shift+H 划掉过时内容；标记重点
上标 / 下标 — 注释编号、化学式（H₂O）
注释 Ctrl+Shift+/ 写成 <!-- -->，预览里不显示，给自己或协作者看
行内公式 — $E=mc^2$
键盘键 — 把 Ctrl+S 渲染成按键样式
链接 Ctrl+K 按设置插入 [文字](地址) 或 [[页面]]
插入本地图片… Ctrl+Shift+I 直接打开文件框/手机相册；粘贴截图也会自动存到 assets/。网络图片用「从网络插入图片…」
清除格式 Ctrl+\ 从别处粘来的花格式一把清掉

五、视图（View）

视图菜单管"看得见什么"。分三组：模式、界面元素、编辑辅助。

功能 快捷键 解决什么
源码模式 Ctrl+/ 检查 Markdown 原文、批量处理格式
阅读模式 Ctrl+E 只读浏览；表格变静态、编辑工具隐藏
左侧栏 Ctrl+Shift+L 专心写作时收起文件树
右侧栏 — 打开日历/大纲/反链出链/最近文档；其他面板在空白处右键勾选
日历显示 右键日历标题 周起始日 / 是否显示周数 / 农历，就地切换
大纲外观 设置 → 内置插件 → 浮动大纲 收起形态（自动/刻度条/悬浮图标）、左右位置、刻度长度；刻度右键「外观」也能改刻度长度
文件 / 搜索 / 标签 Ctrl+Shift+2 / 3 左栏切到对应页
定位文件列表 Ctrl+Shift+E 键盘流：焦点跳到左栏树，↑/↓ 选、Enter 打开
下一个 / 上一个文件 Ctrl+Alt+PageDown / Ctrl+Alt+PageUp 不用回文件树，直接按列表顺序翻下一篇
切换标签页 Ctrl+Tab / Ctrl+Shift+Tab 打开的文档之间轮换
面板（子菜单） Ctrl+Shift+1 等 内置大纲/出链 + 插件注册的面板都在这里
反向链接 — 看"谁引用了我"（文末反链面板）
悬浮大纲 — 悬浮卡形式的大纲，不占右栏
专注模式 F8 只亮当前段，其余淡化
打字机模式 F9 输入行始终停在屏幕中间
状态栏 — 右键切换「跟随正文 / 通栏」或隐藏；视图 › 状态栏 恢复。设置里可开启文档路径面包屑（单击文件夹浏览卡片，右键在树中定位）。更新提示在标题栏，不依赖状态栏
文件夹浏览 状态栏路径 / 附件面包屑 / 文件树文件夹右键 / 文件树空白右键 / 工作区标题右键 / 侧栏 ⋯ 文件夹与非 Markdown 文件同置顶、无卡片边框、类型图标与名称左右排布；笔记/图片在下方卡片区，卡片模式 3:2 横向比例；卡片 / 列表 / 瀑布流与卡片大小可调（列表为单行：图标 + 名称 + 字数/时间，小屏默认列表并隐藏瀑布流；瀑布流按文件大小分高度档位、长文封顶 600px，加载摘要不改变列高），选择会记住；点笔记打开编辑器，点图片/附件打开预览，点文件夹下钻；卡片右键与文件树同一套菜单；右键文件夹在文件树中定位
工具栏（子菜单） — 默认只开顶部全宽工具栏；底部 / 浮动 / 格式栏按需开关。布局可在设置 › 插件 › Editing Toolbar 里切全宽 / 靠左 / 居中
放大 / 缩小 / 实际大小 Ctrl+Shift+= / - / 0 字号缩放；菜单里不再放这三项，命令面板和快捷键仍可用，正文里也可 Ctrl+滚轮
思维导图 Ctrl+Shift+M 当前文档的导图视图；文件树 / 文件标签页右键也能直接打开目标文件的导图
重新打开关闭的标签页 Ctrl+Shift+T 误关文档的快捷退路
开发者工具 Shift+F12 桌面版打开 WebView 检查器；浏览器版会提示用 F12
全屏 F11 沉浸写作
重新加载 — 界面异常时的软重启（不丢自动保存的内容）

「视图 › 面板」是动态的：装了插件，它注册的右侧面板会出现在这里，不需要额外找入口。

六、帮助（Help）

菜单只保留学习入口、启动统计与关于；检查更新 / 更新日志 / 问题反馈移到标题栏「?」的快捷菜单。语法演示、Markdown 参考、数据视图指南与其余诊断命令仍在命令面板（Ctrl+P）里可搜到。

功能 解决什么
帮助中心 完整手册（写作、整理、导出、设置）
欢迎文档 第一次用时的示例与说明
快捷键 全部命令与当前绑定（也在 设置 › 快捷键）
启动统计 查看当前启动时间与耗时构成；其余诊断命令收进命令面板
关于 版本、许可、致谢
标题栏「?」 检查更新 / 更新日志 / 问题反馈；反馈只在你提交时发送

七、命令面板里还有（菜单里不放的）

按 Ctrl+P 搜得到，但没进菜单——因为它们要么是一次性整理动作，要么属于设置。

7.1 排版整理（对全文或选区做一遍就结束）

功能 解决什么
整理中文排版… 中英文之间补空格、标点统一——从别处粘来的稿子最需要

压缩连续空行… 多个空行压成一个

表格前后补空行… 表格贴着段落导致渲染异常时，一键补齐

八、设置页速查

页面 解决什么 关键项

九、界面区域速查

区域 有什么 常用动作
标题栏 侧栏开关、前进后退、标签栏、更多、右栏开关 拖拽可移动窗口（桌面）
标签栏 文档标签 + 左侧「所有标签」+ 右侧「新建空白页」 拖动重排；右键关闭；列表里有相对时间与「撤销关闭」

右栏 日历、大纲、反链/出链；最近文档等默认不挂 拖标签换区；右键 tab：关闭/撤销/添加面板；空白处右键勾选视图
正文 所见即所得编辑区 右键：返回、行宽、阅读模式；Ctrl+滚轮 缩放
状态栏 视图模式按钮、模式标记、保存指示、字数 右键可隐藏；异常时才显示保存文案
