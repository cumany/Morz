更新日志

这里记录每个版本的完整更新说明。应用内「帮助 → 检查更新」只显示摘要，详细内容以本页为准。
当前版本 0.3.2（内测） / 0.1.2（免费）。

0.2.3 与 0.2.4 未单独分发包，改动都包含在 0.2.5 中。

0.3.2（内测）

编辑

  • 输入三个反引号时保持普通文本；继续输字母才弹语言候选，回车生成成对围栏
  • 有序列表被切开后自动接续编号；缩进列表退格后光标停在标记之后，继续输入直接进正文
  • 新建笔记后行内重命名不再卡住；另存为弹窗完整中文化；全选 Callout 时标题不再翻成源码
  • 空图表 / 公式围栏仍可编辑（不再吞掉正文）

思维导图

  • 空格 + 拖动平移、空格 + 滚轮缩放、Shift + 滚轮横向滚动
  • 右键拖动平移，左键框选；新增概览与聚焦快捷键；列表组可拖到标题下面
  • 缩放与平移更跟手

图谱

  • 局部图谱的邻居标签自动避让，密集节点不再重叠；悬停时让位的标签会回来

界面

  • 状态栏默认全宽；编辑工具条默认靠左
  • 最近列表显示时间标签；右栏宽度异常修复
  • 设置弹窗不再被广告拦截规则误杀

免费版

  • 日历 / 每日笔记进入免费版：月历面板、每日笔记、模板与分享落点直接可用
  • 免费版里的内测功能灰显项，点击改为跳网页版对应演示并自动加载演示文档

插件

  • 图床改为可安装的插件；文件夹浏览拆成内置插件，可在「内置插件」里开关
  • 文件夹浏览新增「点击文件夹进入浏览视图」；插件可以给文件树加图标与右键菜单
  • 分栏写作改名「分节卡片」，子列自动对齐，支持画布平移

网页版

  • 全部功能开放体验，内测功能标注 Beta；新增按功能直达的演示文档（?demo=）

Android

  • 主屏小组件与磁贴可以直接快速记录，不打开应用也能写入笔记

0.1.2（免费）

  • 日历 / 每日笔记进入免费版：月历面板、每日笔记、模板与分享落点直接可用
  • 与内测版同源：编辑、列表、Callout 与插件体验的修复同步到免费版

0.3.1（内测）

手机更顺

  • 大库滚动不再掉帧；切换文件夹不再闪白
  • 右栏日历不再拖慢整机：真机反馈里一次运算占用主线程 2.5 秒，现在约 0.07 秒
  • 窄屏下的工具栏、侧栏与设置排版修正

Word

  • Word 文档可以直接打开预览，不用先转换；导入保留标题、表格与图片

0.1.1（免费）

  • 与内测版同源：手机端性能修复同步到免费版
  • Word 文档可直接预览，导出 Word 结构更稳

0.3.0

性能

  • 右栏日历不再拖慢整机：真机反馈中一次运算占用主线程 2.5 秒，现在单次绘制约 0.07 秒
  • 大文档输入更跟手：50 万字符文档输入延迟 P95 5.3ms
  • 表格里打字不再重建整篇排版；长文滚动只更新可见部分
  • 上万文件的文件夹滚动更顺，切目录不再闪
  • 搜索面板分批出结果；启动后不再每秒重扫整个库

分栏写作（新视图）

  • 列 = 标题层级，卡 = 文档小节；点卡在右侧展开子级，直接在卡里写正文并写回 Markdown，一步撤销
  • 支持全屏编辑单张卡；改名、新增子卡/同级卡、上下移动、删除、定位原文

全局图谱

  • 改成沉浸式视图：全屏画布与悬浮工具条

导出

  • 新增长图导出与「分享为图片」
  • Word 中图表颜色与表格结构修正；分享卡片排版对齐

编辑

  • 新建列表项插到当前父级下；HTML 块内相对图片可显示；裸链接遇中文标点正确截断

数据安全

  • 外部修改不会再被自动保存覆盖；快速捕获草稿重启后保留

其他

  • 新增「Plain」阅读主题；frontmatter 中的链接参与索引与重命名改写；每日笔记支持周期预设；工具条图标与顶部布局菜单

0.2.13

更新

  • 手机上检查更新不再报「网络异常」：更新信息改由应用内网络层获取，不再受浏览器跨域限制
  • 增加备用更新地址：主站不通时自动换镜像，弱网或被拦截时更容易成功

其他

  • 应用内反馈、图床、插件市场下载在手机上同样改走应用内网络层，之前会被跨域策略拦掉

0.2.12

文件历史

  • 历史时间显示更完整：「2026年11月20日 周五 10:30」，一天内的版本另标「刚刚 / N 分钟前」

文件夹浏览

  • 任意目录规模下滚动更稳：切换文件夹不再闪白，滚动不再卡顿
  • 卡片预览更干净：正文里的链接、标记不再混进预览文字
  • 文件夹与文件行更紧凑，图标与名称对齐

导图

  • 提升为根节点的一级标题不再被框选或删除误伤

手机

  • 低配机型自动进入轻量模式，启动与滚动更顺

命令面板

  • 拼音检索覆盖新增命令

0.2.11

导图

  • 深层节点可以逐层下钻查看

链接与块引用

  • 块有了真实范围：悬停显示被引用次数，点击直接打开引用列表
  • 输入 [[笔记^ 打开块选择器，候选里能看到块的正文摘要
  • 链接写到一半时方括号不再消失；光标碰到链接会显示完整写法
  • 断链会在状态栏提示数量；标题末尾的块 id 不再计入标题文字

文件夹浏览

  • 文件夹、笔记、图片、PDF / Word 各有自己的卡片样式，笔记卡片直接显示正文预览
  • 卡片右键复用文件树的完整菜单；点文件夹就地下钻，返回时滚动位置不丢
  • 每个文件夹记住自己的浏览方式与缩放

文件历史

  • 已删除笔记的历史不再保留

命令面板

  • 从文件管理器用 Morz 打开 .md 更可靠

  • 性能：大库索引停滞时自动降级，不再弹窗打断

0.2.10

卡死与性能（重点修复）

  • 修复打开或滚动大文档后界面失去响应：块级装饰与编辑器视口互相触发，形成永不收敛的重建循环（实测 3160 次空更新、DOM 节点涨到 36 万）。现在块装饰只由文档状态驱动；2100 篇、600MB 的库连续滚动 120 秒不再挂起
  • 索引解析移入后台 Worker：大库启动索引时不再与滚动抢主线程，打字更跟手；Worker 不可用时自动回退
  • 只索引 Markdown；链接图改为异步分片重建，冷启动不再被一次性解析阻塞
  • 文末反链改为只保留右栏「反向链接 / 出链」（最多 200 条）：文末长列表是先前卡顿与内存上涨的主因之一；「视图 › 反向链接」仍可用
  • 图片加载失败不再每 2 秒自动重试（每次重试都会重建整篇装饰），改为切换文档或 60 秒后自然重试
  • 打字时块装饰按变更范围增量更新，不再每次按键重建全文

Android

  • 划词菜单改由独立入口接收：在 Edge 等应用里选中文字 → 划词工具条 → Morz，工具条立即关闭并直接进入 Morz
  • 分享 / 划词 / 打开文件改为先落盘再确认：进程被杀也不会丢，重启后自动补投且不重复
  • 启动页去掉自绘遮罩，只保留系统启动图与页面内 logo，不再出现双 logo 或白屏
  • 应用内更新：启动时检查新版本（12 小时最多一次），有更新可直接在应用内下载，再按系统提示安装
  • 外部意图 1.5 秒无响应才重载页面，任务 30 秒没有任何进展才处理，慢写入不再被误判

界面

  • 浮动大纲重做：一套卡片 + 自动 / 刻度条 / 悬浮图标三种收起形态，入口在 设置 → 内置插件 → 浮动大纲；卡片可拖动、固定、拖拽重排标题
  • 状态栏右键可在「跟随正文 / 通栏」之间切换或隐藏
  • 思维导图：Ctrl+Shift+M 打开；文件树与文件标签页右键可直接打开目标文件的导图
  • 手机：长按文件 / 文件夹弹出底部操作菜单；搜索面板占满整屏；设置开关放大到更易点的尺寸
  • 脚注可直接在正文里编辑，表格中的脚注一并覆盖
  • 快捷键设置每条绑定都有「清除」按钮（等价录键时按 Del）
  • 编辑器细节：粗体方括号、Callout 内的 HTML、焦点环
  • 更新说明打开时直接聚焦标签页，底部附官网更新日志地址

0.2.9

Android 稳定性（重点修复）

  • 修复反复「闪退」：内存不足时系统会回收 WebView 的渲染进程，此前应用会被连带关闭；现在接管这一事件，前台被回收时页面自动恢复，后台被回收则回到前台时恢复，全程应用不再退出
  • 恢复过程保留打开的文档与草稿；渲染进程死亡不再产生任何可感知的退出
  • 连续异常退出时自动进入安全启动（跳过会话恢复），避免「进不去」；提示条可点「重新尝试恢复会话」

Android 交互

  • 系统返回键按层级关闭：侧栏 / 文件夹层级 → 弹窗与命令面板 → 设置详情 → 思维导图等插件视图 → 最后才是「再按一次返回退出」，不再直接最小化到桌面
  • 浏览器或其他应用「分享」文字到 Morz 不再停在启动画面：分享内容改为等页面就绪后投递，冷启动也可靠落入当日笔记
  • 内置指南里的「导出备份」「选择文件夹…」按钮文字不再溢出边框

修复

  • 思维导图双指缩放不再误触节点拖拽或弹出内容卡
  • 正文字号调大后，指南里的动作按钮高度跟随字号，文字不再顶出上下边框

其他

  • 帮助菜单新增「更新说明」：新标签打开内置更新日志，手动安装的包也能随时查看
  • 诊断增强：记录上次会话是否异常结束、连续闪退计数与本机 Java 崩溃日志（只存在本机，导出诊断时附带）

0.2.6

思维导图

  • 双击节点原地编辑文字（F2 同义）；右键或触摸长按打开操作菜单，按节点类型显示编辑、新建、升降级、移动、复制、定位原文、删除
  • 折叠按钮改为常见语义：展开显示「−」、收起显示「+」；菜单里可「展开全部」
  • 空白处双击不再新建节点；拖节点到另一个节点仍是调整结构
  • 拖节点到空白处，展开并固定该节点的内容卡；卡片贴近触发节点，可遮挡其他内容
  • 侧栏切换文件、「下一个 / 上一个文件」都留在导图视图里；每个文件记住自己的缩放位置
  • 导出整张导图为 PNG（2×）或 SVG，大图带淡淡的水印；小图保持干净

工作区

  • 工作区菜单每行行尾改为「…」：设为默认 / 在文件管理器中显示 / 复制路径 / 移出列表
  • 动作菜单不再收起工作区列表；底部「最近文件夹」可快速切换

修复

  • Emoji 短名 :+1: / :-1: 正常显示，不再停留在源码
  • Obsidian %%…%% 注释里的双链与标签不再进入反链、图谱和未链接提及
  • 思维导图里 Obsidian 注释不再变成空白节点
  • 5,000 节点的大图打开更快（约 2 秒），平移保持流畅

0.2.5

自 0.2.2 以来的累计更新。

思维导图视图（新）

  • 内置插件「思维导图视图」（Mod-Shift-M）：把文档的标题与列表投影成导图，可浏览也可直接编辑
  • 双击节点定位原文；Enter 新建同级、Ctrl+Enter 新建子级、Tab/Shift+Tab 升降、Ctrl+↑↓ 移动、F2 改名、Delete 删除
  • 拖拽重排带落点预览，列表与标题跨类型禁放；一次操作一步撤销
  • 折叠状态、相机位置、内容开关按文档记忆，刷新后原样回来
  • Ctrl 悬停预览卡片，可钉住、可多框并存；滚轮平移，Ctrl+滚轮或触控板捏合缩放，双击空白新建
  • 「内容」开关控制正文与代码块是否显示；长标签按真实字体宽度截断，不溢出节点框

图片与图注

  • 插入图片自动优化：关闭 / 自动 WebP / WebP / JPEG 四种模式，质量与最长边可调；SVG、GIF、HEIC 原样保存
  • 插入重命名：保留原名 / 日期前缀 / 内容哈希 / 自定义模板（{date} {time} {name} {hash}）
  • 图注自动编号：文档级开关、起始号、前缀与分隔符；编号是派生显示，不改正文，导出 HTML/PDF 同步
  • 删除附件前先扫描其他笔记的引用，提示后再删

新建即落盘

  • 桌面首次启动在「文档/Morz」建主库，提示条显示真实路径，并提供「更改位置…」
  • 内置帮助库统一叫「使用指南 / Guides」；内置文档副本落到当前工作区，引用图片一起复制
  • 收集箱默认指向新库，日历、每日笔记与全局捕获有默认落点

阅读与写作

  • 章节折叠插件：标题章节与代码块折叠，光标进入自动展开；折叠状态按笔记记忆
  • 阅读模式新增浮动提示与「隐藏图片」纯文字校对
  • 只读大表格窗口化：1 万行表格的 DOM 从 5 万节点降到约 260

移动端

  • 标题栏、状态栏与标签的触控区放大到 40px 以上，状态栏文字对比度提升
  • 手机设置页头部只留标题：重置移到页底，关闭交给系统返回手势
  • 大纲在手机上首次使用自动收成悬浮图标，不占正文宽度

插件与 SDK

  • SDK v1.4：插件视图可接管标题栏工具条；新增折叠 API 与 vault.attachments()
  • 新内置插件：章节折叠、摘出为新文档、未引用资源清理、思维导图视图
  • 插件视图在刷新后恢复上次打开的那一个

修复

  • PDF 导出样式只作用于导出过程，打印结束即移除，不再影响编辑器
  • 侧栏空文件夹不再显示 0
  • 思维导图：多行段落改名不再吞行、有序列表编号自动重排、点选后方向键立即可用
  • 空草稿的会话恢复不再报「位置越界」；回收站为空时「清空」按钮置灰

  • 工作区切换菜单行尾有「设为默认」标签；同名图片与附件按路径引用

阅读与写作

  • 章节折叠内置插件：标题章节与代码块折叠，光标进入自动展开
  • 阅读模式可隐藏图片，进入纯文字校对
  • 导出 HTML/PDF 支持标题自动编号（正文不写号）
  • 图片查看器支持滚轮缩放、拖拽平移、双击复位、+/- 快捷键
  • 文件树可为每个文件夹显示笔记数

移动端

  • 触控区放大到 40px+，状态栏对比度提升，手机上品牌标让位给文档名
  • 手机设置页头部只留标题；大纲首次使用自动收成悬浮图标
