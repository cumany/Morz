## 安装与启动

**Q：Windows 提示"Windows 已保护你的电脑"怎么办？**
A：安装包未做代码签名。点「更多信息」→「仍要运行」。正式签名证书正在计划中。

**Q：macOS 提示"无法验证开发者"？**
A：右键应用 →「打开」，或在终端执行 `xattr -dr com.apple.quarantine /Applications/Morz.app`。

**Q：手机能装吗？**
A：Android 装 APK；iPhone/iPad 用网页版并「添加到主屏幕」，可离线使用。

**Q：启动后是空白页，我的文档呢？**
A：看侧栏和标签。空白页表示当前没有打开的文档，不是数据丢了；文件还在你的文件夹里。

**Q：能同时装两个版本吗？**
A：Windows 安装包会覆盖同名应用；便携版 `.exe` 可以单独放。

## 文件与工作区

**Q：打开文件夹和打开文件有什么区别？**
A：文件夹 = 工作区，有文件树、全库搜索、标签、反链；单文件只有一篇，没有这些。

**Q：不小心把「我的文档」或 GitHub 代码库当工作区打开，Morz 卡死、下次启动还卡怎么办？**
A：正常流程已经能脱身，不需要命令：

- 索引超过 **15 秒**会出现「停止索引」；停止后只加载根目录，搜索/反链只覆盖已加载内容，可随时「继续索引」。
- 停止或异常退出后，**下次启动会直接以“只加载根目录”打开上次工作区**，不会自动全量索引。
- 只跳过 `.` 开头目录、`node_modules`、`__pycache__`、`__MACOSX`；`dist`、`build`、`Pods` 这类正常名字不会误跳。

如果连窗口都打不开（极端情况），才用应急安全模式：

- Windows：`& "$env:LOCALAPPDATA\Morz\morz.exe" --safe-mode`
- macOS：`open -a Morz --args --safe-mode`
- Linux：`morz --safe-mode`

进去后重新选一个**只放笔记的文件夹**。

**Q：能同时开多个文件夹吗？**
A：能。它们是多个工作区，侧栏顶部切换，各自记住自己的现场。

**Q：双击 `.md` 会用什么打开？**
A：安装桌面版后，系统可能默认用 Morz 打开；也可以在系统设置里改默认程序。

**Q：「导入副本」和「打开」有什么区别？**
A：打开是直接编辑原文件（文件夹工作区）；导入副本会把 `.md` / `.txt` / `.html` 读进来**复制一份到当前工作区**并打开，HTML 自动转成 Markdown，源文件不动。

**Q：外部文件（不是从 Morz 打开的文件夹）双击后放哪？**
A：设置 › 通用 › 文件 ›「外部文件打开规则」：智能判定（属于已打开工作区就切过去）/ 文件优先（只开新标签）/ 按工作区。

**Q：文件在同步盘里被改了，Morz 会怎样？**
A：没有本地修改时自动重载；有未保存修改时按「磁盘文件被外部改动时」的策略处理。

**Q：卸载 Morz 会删我的笔记吗？**
A：桌面版不会。Android 用草稿目录会删，授权文件夹不会。

## 写作

**Q：为什么回车只换一行，不是新段落？**
A：所见即所得要求"看到几行就是几行"。空一行（连按两次回车）才是新段落。

**Q：想段内换行怎么办？**
A：`Shift+Enter`，或在源码里行尾留两个空格。

**Q：为什么源码和预览看起来不一样？**
A：实时预览会把 `**粗体**` 渲染成粗体，光标所在行会露出源码片段；把光标移开就恢复渲染。想看全部源码按 `Ctrl+/`。

**Q：为什么点链接不直接跳转？**
A：实时预览里单击链接会先弹一个小气泡显示地址，点「打开」才跳，避免误触；`Ctrl`/`⌘`+点击直接打开。

**Q：每日笔记和大纲视图是什么关系？**
A：每日笔记默认就是大纲形式：`# 日期` + 一条空 bullet，只允许列表，圆点下钻、行尾折叠。也可以在 设置 › 通用 › 每日笔记 改成普通文档。

**Q：边注 `^[...]` 导出后去哪了？**
A：PDF/Word 里变成文末编号脚注；HTML 里仍是页边注。

**Q：图片粘贴后存哪了？**
A：默认存到文档旁的 `assets/` 文件夹，正文插入相对路径。位置可在 设置 › 图片 改。

**Q：怎么插入表格？**
A：`Ctrl+T`；或输入 `| 列1 | 列2 |` 后回车自动补分隔行。

## 表格

**Q：公式支持哪些函数？**
A：目前 `SUM`、`AVERAGE`，以及四则运算、括号、多区域；函数会继续增加。

**Q：为什么格子里显示 `=SUM(...)` 而不是数字？**
A：正在编辑这个格子时显示源文，光标移开就显示结果。

**Q：能撤销一次填充吗？**
A：能。拖完填充柄按一次 `Ctrl+Z` 撤销整次填充。

**Q：为什么第一次 `Ctrl+Z` 退了一整格？**
A：这是刻意的：在表格里逐字退很难用。整格回退后继续按，会沿操作路径退回上一个改过的格子。

**Q：能粘到 Excel 吗？**
A：能。选中区域 `Ctrl+C` 再粘到 Excel；从 Excel 复制也可以直接粘回表格。

## 导出

**Q：PDF 为什么没有侧边书签？**
A：Windows 桌面版和 Android 是直接生成 PDF（带书签）；macOS / Linux 走系统打印对话框，页码正常，但系统打印不写书签。

**Q：PDF 目录没有页码？**
A：需要在正文里插入 `[TOC]`，导出时才会填真实页码。

**Q：导出的 Word 打开是乱码/缺字体？**
A：Morz 使用宋体 + Consolas；如果系统缺字体，Word 会替换。可在系统里装思源宋体获得一致效果。

**Q：Word 里公式是图片，能编辑吗？**
A：块级公式导出为图片（保证版面）；行内公式保留 TeX 文本。

**Q：导出的 HTML 图片在哪？**
A：默认内嵌为 data URL，单文件即可分享。

**Q：能导出整个库吗？**
A：文件 › 工作区 › 导出全部文档（备份），或 导出 › 发布为静态站。

## 性能

**Q：大文档卡怎么办？**
A：关闭实时预览（`Ctrl+/` 切源码）可显著降低开销；也可以把长文档拆成多篇用双链组织。

**Q：打开很慢？**
A：检查 设置 › 通用 › 索引 是否开启了缓存；文档特别多时首次索引会慢一次。

## 隐私与数据

**Q：会上传我的笔记吗？**
A：不会。没有账号系统，也没有云端；联网只用于更新检查和插件市场。

**Q：有云同步吗？**
A：没有。把文件夹放进你自己的同步盘即可，Morz 不介入同步。

**Q：诊断日志里有我的笔记内容吗？**
A：没有。只有错误堆栈、版本、插件列表等环境信息。

**Q：插件密钥存在哪？怎么删？**
A：桌面存在系统钥匙串，Web / 移动存在应用内密钥区，不写进笔记或设置 JSON。设置 › 密钥 会列出所有保存过的字段（不显示值），可以逐个清除。

**Q：怎么彻底删除数据？**
A：删掉笔记文件夹即可；Android 草稿目录随卸载删除。

## 插件与主题

**Q：Obsidian 插件能用吗？**
A：不能。Morz 有自己的插件 SDK；Obsidian 插件需要重写。

**Q：Obsidian 主题能用吗？**
A：大部分可以。设置 › 外观 › 主题文件夹 → 指向含 `theme.css` 与 `manifest.json` 的目录。

**Q：插件去哪装？**
A：设置 › 第三方插件（注册表 + 本地文件夹）。内置插件在 设置 › 插件 里开关。

**Q：主题改坏了怎么退？**
A：设置 › 外观 › 恢复默认颜色；自定义 CSS 清空即可。
