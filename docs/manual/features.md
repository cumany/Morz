# 功能指南 · 对着菜单看

> **版本**：v0.1.0 · 2026-11-08
> **怎么用**：想知道某个菜单项是干什么的、为什么存在、什么时候该用，按菜单查。
> 快捷键以 Windows / Linux 为准；macOS 把 `Ctrl` 换成 `⌘`。

这份指南不按"功能名"罗列，而是按**菜单**组织——因为那是你实际找功能的地方。每一行都回答同一个问题：**它解决什么麻烦。**

---

## 一、文件（File）

文件菜单管的是"文档的一生"：进来、写、存、交出去、以及工作区级别的整理。

| 功能 | 快捷键 | 解决什么 |
|------|--------|----------|
| **新建** | `Ctrl+N` | 手边有想法但还没想好放哪：先写，位置以后再说 |
| **打开…** | `Ctrl+Shift+O` | 偶尔处理一个散落在别处的 `.md`，不想为它建工作区 |
| **导入副本…** | — | 把外部 `.md` / `.html` / `.txt` 复制一份到当前工作区并打开（HTML 转成 Markdown）；原文件不动 |
| **打开文件夹…** | — | **主力入口**：把整个文件夹变成工作区，左边有树、能搜索、能看反链 |
| **快速打开…** | `Ctrl+O` | 记得标题但不想在树里翻：打几个字直接跳 |
| **最近打开的文件** | — | 换项目后想回到上周那篇，不记得在哪个文件夹 |
| **后退 / 前进** | `Ctrl+Alt+←/→` | 顺着链接跳了三层，想原路退回（含页内标题跳转） |
| **保存** | `Ctrl+S` | 手动落盘（开启自动保存后基本不用） |
| **另存为…** | `Ctrl+Shift+S` | 把这篇文章另起一份，原稿保留 |
| **从磁盘重新加载** | — | 在别的编辑器里改过这篇，用磁盘版本覆盖当前视图 |
| **关闭文档** | `Ctrl+Alt+W` | 收工；有未保存改动会先问 |
| **重命名…** | — | 文件名就是标题，改标题不用去文件管理器 |
| **移动到…** | — | 把笔记挪到另一个文件夹（工作区内） |
| **删除…** | — | 删到回收站，后悔还能捞回来 |
| **在文件列表中定位** | — | 正文里看到一篇，想回到左侧树里看它旁边还有谁 |
| **文档属性…** | — | 看字数、路径、编码、创建/修改时间这些"关于这篇"的信息 |
| **偏好设置…** | — | 全局设置入口（也常驻状态栏左下角） |

### 1.1 导出（子菜单）

| 功能 | 解决什么 |
|------|----------|
| **PDF** | 交付/打印：真分页、页码、TOC 页码、侧边书签（Windows 桌面）；导出前可就地改纸张/页边距/是否带主题 |
| **HTML** | 发网页或存档：跟随当前主题，图片内嵌 |
| **HTML（无样式）** | 只要结构，样式由对方定（贴到已有站点里） |
| **长图** | 整篇按当前主题导成 PNG；导出前可选阅读版/手机宽度和底部标识，太长自动分页打包 zip |
| **Markdown 文件** | 把当前文档导出成 `.md` 副本（不动原文件） |
| **Word (.docx)** | 对方要能改：导航大纲、画廊、Callout、脚注 |
| **复制为 HTML 代码** | 粘到邮件/公众号后台，样式跟着走 |
| **打印…** | 走系统打印（macOS/Linux 的 PDF 也在这里）；打印前可就地改纸张/页边距/是否带主题 |
| **发布为静态站…** | 把整个工作区导出成可直接上传的静态站点 |

> 选中文字后右键「分享为图片」会把选区排成一张带主题的卡片并复制 PNG。

### 1.2 工作区（子菜单）

| 功能 | 解决什么 |
|------|----------|
| **管理工作区…** | 看每个工作区存在哪、切换、在文件管理器中显示、移出列表 |
| **导出全部文档（备份）…** | 换电脑/重装前打包整个工作区 |
| **回收站…** | 误删之后捞回来 |

**文件历史…** 在「文件」菜单里（紧挨「从磁盘重新加载」）：手滑改坏了，按时间点找回这篇的旧版本。

## 二、编辑（Edit）

| 功能 | 快捷键 | 解决什么 |
|------|--------|----------|
| **撤销 / 重做** | `Ctrl+Z` / `Ctrl+Shift+Z` | 写错了往回退；表格里是**整格**退，不是逐字 |
| **剪切 / 复制 / 粘贴** | `Ctrl+X` / `C` / `V` | 常规剪贴板 |
| **复制为 Markdown** | `Ctrl+Shift+C` | 把选中内容连同格式一起拷走，粘到别处仍是 Markdown |
| **复制为 HTML 代码** | — | 粘到支持富文本的地方（邮件、公众号）样式不丢 |
| **粘贴为纯文本** | `Ctrl+Shift+V` | 从网页拷来的内容带着一堆样式，只要字 |
| **全选** | `Ctrl+A` | 两段式：第一次选当前行，再按一次选全文 |
| **选择样式范围** | `Ctrl+Alt+E` | 光标在加粗中间，想一次选中整个加粗范围 |
| **选择行/句** | `Ctrl+L` | 整行选中，不用拖鼠标 |
| **选择单词** | `Ctrl+D` | 快速选中一个词（多光标关闭时的替代） |
| **删除单词** | `Ctrl+Shift+D` | 删掉光标所在词 |
| **上移一行 / 下移一行** | `Alt+↑` / `Alt+↓` | 调段落顺序，不用剪切粘贴 |
| **查找…** | `Ctrl+F` | 当前文档内定位 |
| **替换…** | `Ctrl+H` | 批量改词 |
| **查找下一个 / 查找上一个** | `Ctrl+G` / `Ctrl+Shift+G` | 反复找同一个词 |
| **在文件中搜索…** | `Ctrl+Shift+F` | 忘了在哪篇，搜整个工作区 |
| **插入表情…** | — | 找 emoji，不用记短代码 |

## 三、段落（Paragraph）

段落菜单管"块级结构"。和格式菜单的分界：**格式改行内，段落改整块。**

| 功能 | 快捷键 | 解决什么 |
|------|--------|----------|
| **标题 1–6** | `Ctrl+1`…`Ctrl+6` | 建立层级；导出 PDF/Word 的大纲、TOC 都靠它 |
| **正文** | `Ctrl+0` | 把标题降回普通段落 |
| **提升标题级别 / 降低标题级别** | `Ctrl+=` / `Ctrl+-` | 整篇结构要挪一层，不用逐条改 |
| **表格…** | `Ctrl+T` | 插入表格，填行列数即可 |
| **表格预览** | 右键表格 → 预览表格 / 悬停右上角按钮 | 宽表、长表在弹窗里一屏看全，表头吸顶；打印/导出会按页面宽度重新排版，不会只印出可见的一半 |
| **宽表处理** | 右键表格 → 宽表处理（全局） | 默认适应正文；仍放不下时横向滚动。需要按内容排时可切“按内容横向滚动” |
| **代码块** | `Ctrl+Shift+K` | 贴代码，带语言高亮 |
| **公式块** | `Ctrl+Shift+M` | 独立成行的 TeX 公式 |
| **引用** | `Ctrl+Shift+Q` | 引用他人观点 |
| **有序列表 / 无序列表** | `Ctrl+Shift+[` / `Ctrl+Shift+]` | 列步骤、列要点 |
| **任务列表** | `Ctrl+Alt+X` | 待办清单，可勾选 |
| **切换任务状态 / 标记为完成 / 标记为未完成** | `Ctrl+Shift+X` 等 | 批量改状态，或统一标成完成 |
| **增加缩进 / 减少缩进** | `Ctrl+]` / `Ctrl+[` | 列表层级、代码缩进 |
| **在上方插入段落 / 在下方插入段落** | — | 引用块、表格前后插不进字时的出口 |
| **链接引用** | — | 同一地址多处引用，改一处全改（`[文字][1]` + 定义） |
| **脚注** | `Ctrl+Alt+R` | 补充说明不打断正文 |
| **分隔线** | `Ctrl+Alt+-` | 章节之间断开 |
| **目录** | — | 插入 `[TOC]`，导出时自动填页码 |
| **YAML 元信息** | — | 给文档加标题/标签/日期等属性（属性卡形式展示） |

## 四、格式（Format）

| 功能 | 快捷键 | 解决什么 |
|------|--------|----------|
| **加粗 / 斜体 / 下划线** | `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | 强调 |
| **行内代码** | `Ctrl+Shift+\`` | 术语、命令、变量名 |
| **删除线 / 高亮** | — / `Ctrl+Shift+H` | 划掉过时内容；标记重点 |
| **上标 / 下标** | — | 注释编号、化学式（H₂O） |
| **注释** | `Ctrl+Shift+/` | 写成 `<!-- -->`，预览里不显示，给自己或协作者看 |
| **行内公式** | — | `$E=mc^2$` |
| **键盘键** | — | 把 Ctrl+S 渲染成按键样式 |
| **链接** | `Ctrl+K` | 按设置插入 `[文字](地址)` 或 `[[页面]]` |
| **图片…** | `Ctrl+Shift+I` | 插图；粘贴截图也会自动存到 `assets/` |
| **清除格式** | `Ctrl+\` | 从别处粘来的花格式一把清掉 |

## 五、视图（View）

视图菜单管"看得见什么"。分三组：模式、界面元素、编辑辅助。

| 功能 | 快捷键 | 解决什么 |
|------|--------|----------|
| **源码模式** | `Ctrl+/` | 检查 Markdown 原文、批量处理格式 |
| **阅读模式** | `Ctrl+E` | 只读浏览；表格变静态、编辑工具隐藏 |
| **左侧栏** | `Ctrl+Shift+L` | 专心写作时收起文件树 |
| **右侧栏** | — | 打开日历/大纲/反链出链；其他面板在空白处右键勾选 |
| **日历显示** | 右键日历标题 | 周起始日 / 是否显示周数 / 农历，就地切换 |
| **大纲外观** | 右键大纲刻度 → 外观 | 贴边刻度 / 浮动卡片、等长 / 按层级；左右位置在图标快捷排 |
| **文件 / 搜索 / 标签** | `Ctrl+Shift+2` / `3` | 左栏切到对应页 |
| **定位文件列表** | — | 键盘流：焦点跳到左栏树 |
| **面板（子菜单）** | `Ctrl+Shift+1` 等 | 内置大纲/出链 + **插件注册的面板**都在这里 |
| **反向链接** | — | 看"谁引用了我"（文末反链面板） |
| **悬浮大纲** | — | 悬浮卡形式的大纲，不占右栏 |
| **专注模式** | `F8` | 只亮当前段，其余淡化 |
| **打字机模式** | — | 输入行始终停在屏幕中间（默认不绑键，防误触） |
| **状态栏** | — | 右键隐藏；`视图 › 状态栏` 恢复。更新提示在标题栏，不依赖状态栏 |
| **工具栏（子菜单）** | — | 默认只开顶部全宽工具栏；底部 / 浮动 / 格式栏按需开关。布局可在设置 › 插件 › Editing Toolbar 里切全宽 / 靠左 / 居中 |
| **放大 / 缩小 / 实际大小** | `Ctrl+Shift+=` / `-` / `0` | 字号缩放（正文里也可 `Ctrl+滚轮`） |
| **全屏** | `F11` | 沉浸写作 |
| **重新加载** | — | 界面异常时的软重启（不丢自动保存的内容） |

> 「视图 › 面板」是动态的：装了插件，它注册的右侧面板会出现在这里，不需要额外找入口。

## 七、命令面板里还有（菜单里不放的）

按 `Ctrl+P` 搜得到，但没进菜单——因为它们要么是**一次性整理动作**，要么属于设置。

### 7.1 排版整理（对全文或选区做一遍就结束）

| 功能 | 解决什么 |
|------|----------|
| **整理中文排版…** | 中英文之间补空格、标点统一——从别处粘来的稿子最需要 |
| **删除行尾空白…** | 清掉不可见的行尾空格（Git diff 变干净） |
| **压缩连续空行…** | 多个空行压成一个 |
| **去除空行…** | 普通段落之间不再留空行；标题/列表/引用/代码块/表格等块元素前后保留一个 |
| **表格前后补空行…** | 表格贴着段落导致渲染异常时，一键补齐 |

### 7.2 列表操作

| 功能 | 快捷键 | 解决什么 |
|------|--------|----------|
| **上移列表项 / 下移列表项** | `Ctrl+Shift+↑/↓` | 调整条目顺序 |
| **折叠列表项 / 展开列表项** | `Ctrl+Shift+[` / `]` | 长列表只看大项 |

### 7.3 主题

| 功能 | 解决什么 |
|------|----------|
| **主题列表** | 换内置主题 |
| **选择主题文件夹… / 打开主题文件夹 / 刷新主题** | 用 Obsidian 生态的 `.css` 主题 |
| **从内置主题创建…** | 复制一份内置主题再改，改坏了能退回 |
| **导入主题… / 管理主题…** | 从文件导入、移除不需要的 |

### 7.4 其他

| 功能 | 解决什么 |
|------|----------|
| **上一个标签页 / 下一个标签页** | 不开列表也能切 tab |
| **关闭其他标签页 / 关闭右侧标签页** | 收工时一次关掉一片 |
| **浮动大纲** | 右栏里的固定大纲面板（与“悬浮大纲”区别：一个占栏、一个悬浮） |
| **命令面板** `Ctrl+P` | 忘了快捷键时的万能入口（中英文都能搜） |
| **管理工作区…** | 重命名、移除工作区 |
| **第三方插件…** | 安装/停用插件（内置 SDK） |
| **检查插件更新…** | 插件也有版本 |
| **安装应用** | 浏览器里把 Morz 装成 PWA（离线可用） |
| **打开今天的笔记**（日历插件） | 创建/打开今天的每日笔记；大纲模式下就是一条空 bullet |
| **导出诊断信息… / 清除诊断信息**（内部测试版） | 排查问题用，内容只在本机 |

## 八、设置页速查

| 页面 | 解决什么 | 关键项 |
|------|----------|--------|
| **通用** | 保存、索引、文件、MCP | 自动保存、恢复上次文档、文件历史条数/天数、文件排序、外部文件打开规则、磁盘改动策略、MCP 访问 |
| **快捷键** | 所有命令可重绑 | 搜索命令、按新组合、Backspace 取消 |
| **编辑器** | 排版与编辑行为 | 字号/行宽/行高/缩进、链接格式、拼写检查、自动配对、粘贴整理、工具栏显隐 |
| **外观** | 主题与界面 | 明暗模式（跟随系统 / 浅色 / 深色）、八套主题、主题设置（⚙）、主题文件夹、自定义颜色 |
| **主题市场** | 装主题 | 浏览、安装、检查更新 |
| **自定义 CSS** | 最后的样式自由 | 全局 CSS，覆盖主题变量 |
| **图片** | 图片存哪、怎么插 | 插入位置（`assets/` 等）、目录名、表格/图注行为 |
| **导出** | 导出默认值 | HTML/PDF 跟随主题、PDF 纸张、页边距 |
| **插件** | 内置插件开关 | Dataview、边注、任务、图谱等 |
| **第三方插件** | SDK 插件 | 安装、启停、权限 |
| **密钥** | 插件密钥集中管理 | 列出已保存的字段（不显示值）、逐个清除 |
| **隐私** | 应用锁 | PIN / 生物识别、自动锁定、恢复码 |

## 九、界面区域速查

| 区域 | 有什么 | 常用动作 |
|------|--------|----------|
| **标题栏** | 侧栏开关、前进后退、标签栏、更多、右栏开关 | 拖拽可移动窗口（桌面） |
| **标签栏** | 文档标签 + 左侧「所有标签」+ 右侧「新建空白页」 | 拖动重排；右键关闭；列表里有相对时间与「撤销关闭」 |
| **左侧栏** | 文件 / 搜索 / 标签 三页；顶部切换工作区 | 右键文件：重命名、移动、删除、在系统中显示 |
| **右栏** | 日历、大纲、反链/出链；其他视图默认不挂 | 拖标签换区；右键关面板/撤销；空白处右键勾选视图 |
| **正文** | 所见即所得编辑区 | 右键：返回、行宽、阅读模式；`Ctrl+滚轮` 缩放 |
| **状态栏** | 视图模式按钮、模式标记、保存指示、字数 | 右键可隐藏；异常时才显示保存文案 |

## 附：这份指南与《手记》的分工

- **《手记》**（`index.md`）：讲为什么、怎么开始、一篇文档怎么写完——适合从头读。
- **《功能指南》**（本文）：按菜单查"这个项是干嘛的"——适合边用边查。

两份文档会随版本一起更新；如果发现菜单里有而本文没写的项，告诉我补上。
