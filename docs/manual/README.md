## 三条最常走的路

**① 第一次用（5 分钟）**

1. 打开 Morz → 点 **打开文件夹…**，选一个放笔记的文件夹
2. 左侧点任意 `.md`，或按 `Ctrl+N` 新建
3. 直接写——回车换行，空一行分段

→ 详见 [第一次打开](start.md#第一次打开) 与 [写第一篇](start.md#写第一篇文档)

**② 把一篇笔记写成能交出去的样子**

1. 用标题（`Ctrl+1`…`Ctrl+6`）分层
2. 需要数据时插表格（`Ctrl+T`），公式写在格子里（`=SUM(B2:B3)`）
3. 文件 › 导出 › PDF 或 Word

→ 详见 [表格](write.md#表格) 与 [导出](export.md)

**③ 找一篇忘了在哪的笔记**

1. `Ctrl+O` 按标题找
2. `Ctrl+Shift+F` 按内容找
3. 都不记得？左侧「标签」或右侧「大纲」

→ 详见 [整理与查找](organize.md)

## 找不到答案？

- 先看 [常见问题](faq.md)，那里覆盖了 90% 的疑问
- 命令忘了在哪：`Ctrl+P` 打开命令面板，输入中文关键词（如"表格"）直接搜
- 还是不行：把现象、系统版本、是否本地文件夹和复现步骤告诉我们
